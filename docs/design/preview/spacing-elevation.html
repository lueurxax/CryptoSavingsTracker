Elevation tiers
Four shadow tokens — every surface picks exactly one. Ad-hoc shadow literals are blocked by lint.
--elev-none
0 dp · no shadow
Embedded list rows, inputs, inline chips
--elev-card
2 dp · y2 blur6 + y1 blur2
Standard surface cards, summary tiles, goal rows
--elev-raised
4 dp · y6 blur16 + amber bloom
Hero dashboard card, commit dock, floating tab bar
--elev-modal
16 dp · y22 blur48 + cool aura
Bottom sheets, alerts, confirmation dialogs
Shadows are pure black with cool/warm aura on raised tiers, so they punch through the midnight wallpaper. Pick the tier by role; never invent a new shadow.
