CryptoSavingsTracker · iOS UI Kit

Three primary screens — Goals, Goal Dashboard, and Plan — recreated from Views/GoalsListView.swift, Views/Dashboard/GoalDashboardScreen.swift, and Views/Planning/MonthlyPlanningContainer.swift. Two phones run the dark-banner theme (midnight + amber); the third runs the light-banner theme (cream + amber + midnight ink) so both brand surfaces are visible side-by-side. Tap a goal in phone 1 to open its dashboard, the Log button in phone 2 opens the half-sheet, and phone 3 has a working commit slider.
